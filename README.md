# Azure First Project

This is my first cloud-infrastructure hands-on project using Terraform to deploy and manage resources in Microsoft Azure.

## Project Overview

The purpose of this project is to learn Infrastructure-as-Code (IaC) by creating Azure infrastructure with Terraform instead of configuring every resource manually through the Azure Portal.

The project is my practical experience with Terraform workflows, Git, GitHub, and GitHub Actions and cloud infrastructure management.

## Technologies Used

- Microsoft Azure
- Terraform
- Azure Resource Manager Provider (AzureRM)
- Linux
- Git
- GitHub
- PowerShell

## Azure Resources

The project includes the following Azure resources:

- Resource Group
- Virtual Network
- Subnet
- Network Security Group
- NSG Security Rules
- Subnet and Network Security Group Association
- Public IP Address
- Network Interface
- Linux Virtual Machine
- Azure Managed OS Disk
